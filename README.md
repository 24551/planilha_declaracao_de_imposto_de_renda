# Planilha de Imposto de Renda

## Sobre o projeto

Esta planilha foi desenvolvida no Microsoft Excel e teve como objetivo construir um sistema voltado para a facilitação no preenchimento dos dados necessários para realização da declaração de imposto de renda.

## Construção técnica

Na construção da planilha, foi realizado o aprimoramento para a facilitação da navegação. Incluí botões que permitem alternar entre as áreas da planilha e utilizei fórmulas de soma para calcular valores automaticamente. Também configurei listas suspensas para padronizar as opções disponíveis e mensagens de erro para alertar quando for digitado um nome que não consta na lista. Além disso, inseri mensagem de instrução para orientar o usuário durante o preenchimento. Por fim, implementei listas suspensas dependentes usando validação de dados. Primeiro, a pessoa seleciona o estado; em seguida, é liberada uma lista dos municípios do estado selecionado.
